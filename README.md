# student-performance-prediction
# Study Time and Student Grades Analysis

## 1. Overview
This project explores the relationship between weekly study time and student grades using data cleaning, summary statistics, group comparisons, correlation analysis, and visualizations.

## 2. Research Question
How is weekly study time associated with student grades across study-time groups, and what limitations apply when interpreting this relationship?

## 3. Dataset
- File: `gourav_study_grades.csv` (synthetic learning dataset generated for reproducibility; no personal student data is included).
- Key columns: `student_id`, `weekly_study_hours`, `attendance_pct`, `final_grade`, and derived `study_group`.

## 4. Tools
- Python, pandas, NumPy, SciPy, Matplotlib, Google Colab

## 5. Limitations & Conclusion
- Higher weekly study hours are positively associated with higher average grades in this dataset, but correlation and group differences do not prove causation.
- Other factors such as attendance, prior preparation, teaching methods, and test conditions also affect student grades.
